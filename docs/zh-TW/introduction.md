# 簡介

## HMG 是什麼

HMG（Holographic Memory Graph，全息記憶圖）是 **AI Agent 的長期記憶系統**。它讓 Codex、Cursor、Claude Code、pi 等程式設計助手跨越會話邊界，記住：

- 專案經驗與架構決策
- 使用者偏好與專案約定
- 已排查的根因與驗證結果
- 已知風險與後續待辦事項

傳統程式設計助手每次會話從零開始，你不得不反覆交代專案背景、反覆解釋「為什麼這裡這樣寫」。HMG 把這些「未來會用到的資訊」沉澱成結構化記憶，在正確的上下文（專案、倉庫、分支）裡按需召回，從而：

- 減少重複溝通
- 保持決策一致性
- 讓新會話快速進入狀態
- 降低跨人協作的資訊損耗

HMG 完全執行在你的本機：記憶資料、索引、嵌入模型都在本地，不經過任何第三方服務。

## HMG 適合做什麼

HMG 把記憶資料儲存在你的本機，適合個人開發者或小範圍本地使用，常見場景：

| 場景 | 說明 |
|------|------|
| 個人開發記憶 | 記住自己專案的約定、踩過的坑、為什麼選某方案 |
| 專案約定 | 程式碼風格、測試命令、部署約束、目錄規則 |
| 架構決策 | 為什麼選 A 不選 B、替代方案、風險、驗證結果 |
| 排障經驗 | 根因是什麼、試過哪些方案、最終怎麼修的 |
| 使用者偏好 | 你穩定的編碼偏好（如「永遠用空格縮排」「測試用 vitest」） |
| 任務交接 | 多天任務跨會話繼續，恢復時知道做到哪、下一步做什麼 |
| 多分支背景 | feature 分支的實驗結論與 main 分支的穩定決策互不汙染 |

> 注意：HMG 的記憶不是聊天記錄的轉儲，而是「以後會複用」的資訊。臨時輸出、完整日誌、一次性指令不應成為長期記憶。詳見 [記憶](concepts.md#memory)。

## 快速整合進 Agent 並享受長期記憶

安裝完成後，只需要兩步：

```bash
hmg setup
hmg init --agent codex
```

把 `codex` 換成 `cursor` 或 `claude` 也可以。接入完成後：

- **會話啟動時**，Agent 自動收到一份記憶簡報（上次交接、關鍵決策、風險、下一步）
- **每輪對話時**，Agent 自動用你的問題預取相關記憶
- **作用域自動隔離**，專案 / 倉庫 / 分支各歸各位，Agent 不需要也不會傳錯
- **寫入完全自主**，Agent 在做出決策、完成任務時自動儲存記憶和交接

自此 Agent 具備長期記憶：同一個專案聊得越久，它越瞭解你的程式碼庫、約定和偏好。

如需解鎖開發者版能力與更高記憶容量，先在官網升級套餐，再在本地執行 `hmg login` 登入（可選，需要聯網）。詳細的宿主差異、hooks、MCP 配置和手動接入方式見 [整合](integration.md)。
