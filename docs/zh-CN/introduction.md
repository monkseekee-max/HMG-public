# 简介

## HMG 是什么

HMG（Holographic Memory Graph，全息记忆图）是 **AI Agent 的长期记忆系统**。它让 Codex、Cursor、Claude Code、pi 等编程助手跨越会话边界，记住：

- 项目经验与架构决策
- 用户偏好与项目约定
- 已排查的根因与验证结果
- 已知风险与后续待办事项

传统编程助手每次会话从零开始，你不得不反复交代项目背景、反复解释「为什么这里这样写」。HMG 把这些「未来会用到的信息」沉淀成结构化记忆，在正确的上下文（项目、仓库、分支）里按需召回，从而：

- 减少重复沟通
- 保持决策一致性
- 让新会话快速进入状态
- 降低跨人协作的信息损耗

HMG 完全运行在你的本机：记忆数据、索引、嵌入模型都在本地，不经过任何第三方服务。

## HMG 适合做什么

HMG 把记忆数据保存在你的本机，适合个人开发者或小范围本地使用，常见场景：

| 场景 | 说明 |
|------|------|
| 个人开发记忆 | 记住自己项目的约定、踩过的坑、为什么选某方案 |
| 项目约定 | 代码风格、测试命令、部署约束、目录规则 |
| 架构决策 | 为什么选 A 不选 B、替代方案、风险、验证结果 |
| 排障经验 | 根因是什么、试过哪些方案、最终怎么修的 |
| 用户偏好 | 你稳定的编码偏好（如「永远用空格缩进」「测试用 vitest」） |
| 任务交接 | 多天任务跨会话继续，恢复时知道做到哪、下一步做什么 |
| 多分支背景 | feature 分支的实验结论与 main 分支的稳定决策互不污染 |

> 注意：HMG 的记忆不是聊天记录的转储，而是「以后会复用」的信息。临时输出、完整日志、一次性指令不应成为长期记忆。详见 [记忆](concepts.md#memory)。

## 快速集成进 Agent 并享受长期记忆

安装完成后，只需要两步：

```bash
hmg setup
hmg init --agent codex
```

把 `codex` 换成 `cursor` 或 `claude` 也可以。接入完成后：

- **会话启动时**，Agent 自动收到一份记忆简报（上次交接、关键决策、风险、下一步）
- **每轮对话时**，Agent 自动用你的问题预取相关记忆
- **作用域自动隔离**，项目 / 仓库 / 分支各归各位，Agent 不需要也不会传错
- **写入完全自主**，Agent 在做出决策、完成任务时自动存储记忆和交接

自此 Agent 具备长期记忆：同一个项目聊得越久，它越了解你的代码库、约定和偏好。

如需解锁开发者版能力与更高记忆容量，先在官网升级套餐，再在本地执行 `hmg login` 登录（可选，需要联网）。详细的宿主差异、hooks、MCP 配置和手动接入方式见 [集成](integration.md)。
